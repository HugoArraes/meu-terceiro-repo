# Notas do Projeto

Arquivo adicionado para praticar o fluxo de trabalho com branches e Pull Requests.

## Fluxo utilizado

1. Criar uma branch a partir da `main`.
2. Adicionar as alterações e fazer o commit.
3. Enviar a branch para o remoto com `git push`.
4. Abrir um Pull Request com `gh pr create`.
5. Fazer o merge do PR e apagar a branch remota.
6. Atualizar a `main` local com `git pull`.
